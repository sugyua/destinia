# Destinia 0.4 Beta — candidata

- `Compilar Destinia.bat` compila os dois hosts por duplo clique, usando o MSYS2 UCRT64 já instalado; parâmetros opcionais selecionam apenas um host.
- `Abrir Destinia.bat` inicia o normal; `Abrir Destinia Zoom 800x480.bat` inicia o zoom em tela cheia, com F11 para alternar.
- Zoom out 800×480 restaurado, com mapas pequenos centralizados e fundo cinza fora do cenário. A versão normal permanece 400×240.
- UI original proporcionalmente menor no zoom; fonte do contador de XP ajustada para manter aproximadamente o tamanho visual da 0.3. Legibilidade e áreas de clique ainda precisam de confirmação no Windows.
- Tela cheia proporcional preservada: imagem 2400×1440 centralizada em monitor 3440×1440. As margens externas também são cinzas.
- Diagnóstico atualizado para o novo zoom e pergunta manual de UI/XP. A compilação e os testes locais não comprovam o gameplay completo da passagem no Windows.

**O log TXT detalhado do jogo fica para a 0.5.** Nenhum novo logger desse tipo foi incluído na 0.4. Os relatórios de diagnóstico existentes continuam funcionando.

Pacote em código-fonte: requer compilação e os dados originais do jogo. Sem EXE Windows pronto, APK, saves ou dependências externas no ZIP. Consulte Dependências no README e INSTALL.md. Compras/rede continuam pendentes; áudio não foi retestado nesta preparação em Linux.

A candidata será publicada somente após revisão e aprovação. Consulte CHANGELOG.md e docs/RELEASE_0.4.md para mudanças e verificações.

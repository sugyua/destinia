Destinia iOS ARM32 diagnostic milestone 0.5.4
Branch: ios/unicorn-poc
Build: 23, unsigned IPA (sign with AltStore or equivalent)
Upgrade over iOS native 0.3.9 without uninstalling to preserve app data.
Bundle ID com.destinia.tcidiagnostic is unchanged.

0.5.4 (Build 23) features:
- Mapeamento refinado para GameSir X5 Lite e controles físicos Xbox / MFi:
  * Botão A: Bate (Ataque principal exclusivo)
  * Botão X: Organiza o inventário quando aberto (hitbox Key 12 / sortBag)
  * Botão B: Volta / Cancela
  * Botão Y & Start: Abrem o Menu / Inventário
  * L1 & R1: Poções (HP e MP)
  * Analógico Direito (RS): Habilidades nos 4 slots (<- slot 0, v slot 1, -> slot 2, ^ slot 3)
  * Select / Options (e cliques L3/R3): Salvar o jogo (botão SAVE da HUD)
- Preservação da fidelidade visual e estabilidade do framebuffer RGB565 sem distorção de cores.

0.5.3 features:
- Ocultação dos botões virtuais da tela (100% transparentes) com supressão de toque durante o uso de controle físico.
- Mapeamento refinado de controle 100% idêntico à versão de PC (layout DualSense / USB-C):
  * Ataque: X (Cruz / buttonA)
  * Voltar/Fechar: Círculo (buttonB)
  * Poção HP: L1 (leftShoulder)
  * Poção Mana: R1 (rightShoulder)
  * Habilidades: Analógico Direito (RS <, RS v, RS >, RS ^)
  * Menu: Start (buttonMenu)
  * Salvar: Select / Options (buttonOptions)

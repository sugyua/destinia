Destinia iOS ARM32 diagnostic milestone 0.3.7
Branch: ios/unicorn-poc
Build: 11, unsigned IPA (must be signed with AltStore or equivalent)
Upgrade over native TCIProbe iOS 0.3.6; preserve CFBundleIdentifier
com.destinia.tcidiagnostic and installed app data. DO NOT uninstall to upgrade.

Real iPhone 15 Pro Max gameplay evidence from 0.3.6 (06 Nov 2026):
- Game progression: completed three tutorial maps and reached first town.
- 7.2-7.3 FPS in the examined scenes, ARM32 132.6-133.1ms per update.
- RGB preparation approximately 0.1ms; RAM approximately 119-124MiB.
- Thermal state transitioned from NORMAL to ELEVADO after longer play.
- Target remains 16 logical updates/sec (62.5ms); NOT YET VERIFIED.

0.3.7 changes:
- Enable the native Grp_drawSimpleClipWImageP RGB565 palette-copy row loop
  acceleration (DESTINIA_NATIVE_SIMPLECLIP=1), leaving its ARM32 clipping,
  control flow, original library on disk, and game timing unchanged.
- Preserve native fill, sprite, heap, ALPHA16, alpha-row, and Dodge16 hooks
  validated in iOS 0.3.6.
- Fix profiler banner layout so TOP ARM32 names are not truncated to one line.
- Keep HUD toggle on three-finger touch and single-frame top-functions
  profiler on four-finger touch. Profiling intentionally slows one frame.
- Bundle original Android 1.0.6 libdestinia_jni.so and assets unchanged.

Reproducible Linux ARM64 GitHub Actions validation:
- Stage navigation run 42267860632, success, all 420 frame hashes identical
  across original baseline, 0.3.6 native optimizations and SimpleClip.
- For frames 300-419, the prior optimized median was 190.0ms and with
  SimpleClip 130.0ms (31.6% reduction in ARM32 time); p90 195 -> 135ms.
- The native SimpleClip hook processed 1,200,150 source image rows.
- These are runner measurements, NOT guaranteed iPhone performance.

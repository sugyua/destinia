Destinia iOS native ARM32 diagnostic milestone 0.3.9
Branch: ios/unicorn-poc
Build: 13; IPA unsigned and must be signed for iPhone installation.
Replace 0.3.8 in-place. Keep bundle ID com.destinia.tcidiagnostic.
DO NOT UNINSTALL to update; preserve game saves and app data.

Measured by user on iPhone, version 0.3.8:
- Gameplay: 15.5 FPS, ARM32 mean 56.1 ms, frame 64.3 ms (peak 67 ms).
- RAM: 126 MiB; thermal ELEVADO after roughly four minutes of gameplay.
- Full native ARM32 TOP profile: Grp_drawClipWImageP (238667),
  Grp_drawSimpleClipWImageP (96474), Grp_drawWPNImage2 (89305),
  _drawMiniMap (55506), Grp_fillRect (53941); numbers are executed
  ARM32 instructions attributed to symbols, NOT function call counts.
- Exact game design target is 16 logic updates/second = 62.5 ms/tick.

0.3.9 change (pacing only, not a graphics code change):
- Move iOS dispatch-source tick deadlines from rounded milliseconds
  to nanoseconds, computed relative to the beginning of each tick.
- Apply a minimum update period of 62.5 ms, never higher than 16 Hz.
- Honor slower game-requested delays, including loading/transitions;
  do not attempt catch-up when ARM32 processing exceeds a tick budget.
- Tighten DispatchSource timer leeway from 5ms to 0.5ms for the 16Hz
  gameplay timer, without busy-waiting.
- Preserve all already validated native graphics hooks from 0.3.8,
  original Android ELF/assets, game logic and save compatibility.
- Preserve 3-finger diagnostics and one-shot 4-finger profiling.
- Add portable C++ scheduling tests in ios/TCIProbe/frame_pacing_test.cpp;
  CI stage workflow runs them ahead of its 420-frame equivalence test.

Validation requirements:
- Portable 16 Hz scheduling arithmetic tests pass.
- Native iOS main.mm compiles successfully with the updated header.
- ARM32 regression and 420-frame identity tests pass.
- Device test still required to confirm sustained 16 FPS and cooler
  thermal behavior. Tighter timer leeway can increase wake precision
  and potentially energy use; thermal effect is not yet verified.

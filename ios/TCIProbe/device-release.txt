Destinia iOS ARM32 diagnostic milestone 0.3.5
Branch: ios/unicorn-poc
Evidence on iPhone (user screenshot, 06 Nov 2026):
- Inside actual gameplay: 3.5 FPS, average ARM32 279.6 ms/frame,
  RGB565 conversion/preparation 0.1 ms/frame.
- Target ~16 FPS requires reducing ARM32 cost below 62.5ms:
  current gap ~4.5x.
- This is a CPU-side ARM32 emulation bottleneck in gameplay, not
  the Objective-C UIKit frame conversion.
Diagnostic features in this milestone:
- Existing three-finger touch shows FPS, ARM32 and RGB metrics.
- Four-finger touch requests profiling ONE following real gameplay frame.
- Result shows top five original ELF ARM32 function names and
  executed instruction counts on screen and in NSLog.
- The profile panel persists until three-finger HUD toggle.
- Profiling is disabled in ordinary frames, and the hooked
  diagnostic frame will be slower than normal gameplay.
- All game assets and original Android ARM32 library are unchanged.
- Graphics accelerated native operations remain enabled.
- Native 64 MiB guest heap can fall back to original Unicorn map.
Purpose:
- Identify gameplay CPU hotspots in actual scene rather than
  optimize the original logo/title screen again.
- No performance improvement is claimed from profiling itself.
User instructions:
1. Install via AltStore over current application; do not uninstall.
2. Enter the scene shown in screenshot.
3. Tap with four fingers simultaneously ONCE, allow profile frame to complete.
4. Screenshot the displayed TOP ARM32 list; send to ChatGPT.
5. Three-finger tap returns to FPS metrics.

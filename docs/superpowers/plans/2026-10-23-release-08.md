# Destinia 0.8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Entregar todos os requisitos aprovados da0.8 antes de iniciar entrega0.9.
**Architecture:** Host C++/Unicorn com componentes compartilhados, contratos ARM verificados e equivalentes web. Sem reescrever o jogo original nem mudar zoom/ritmo.
**Tech Stack:** C++17, SDL2, Unicorn, Node/WebAssembly, PowerShell, GitHub Actions, Sites.
**Spec:** docs/superpowers/specs/2026-10-23-releases-08-09-design.md (aprovada pelo autor).

## Global Constraints

Publicação GitHub/web das0.8 e0.9 já autorizada; não repetir aprovação. Preservar saves, patch local Configurar Destinia.bat e audiência privada do Site. Dependências externas fora dos ZIPs.0.8 completa antes0.9. Não marcar requisito não demonstrado.

## Review Focus

- Interrupção entre gravações de arquivos deve conservar recuperação consistente do save anterior.
- UI transformada não pode deslocar hitboxes, alterar cenário nem prender direção.
- Compra offline não pode mudar cash nem manter rede aguardando.
- Perfil expandido não pode escrever no save clássico nem importar progresso sem confirmação.
- Web mantém toque, preferências separadas e progresso temporário.

### Task 1 — Escrita recuperável de saves
Files: common/safe_save.h, host/main.cpp, host_zoom/main.cpp, tests/safe_save_cases.cpp, tests/test_safe_save.py, tests/runtime_host_cases.cpp.
Interfaces: SaveTransaction::configure(path),begin(),open(path,mode),close(FILE*),finish(success),recover(); arquivos ARM são preparados fora do destino ativo e fechados/validados antes da publicação. Fronteira é chamada ARM do host; várias escritas do mesmo frame pertencem ao lote. Journal em pasta irmã permite recuperar interrupção durante substituições; não é promessa de transação do inventário ainda não mapeado.
- [ ] Escrever testes: destino inalterado antes definish; publicação bem-sucedida; abort; erros de flush/replace; interrupção subprocesso; journal malformado/links preservados; fopen leitura/append/r+ compatíveis.
- [ ] Executar teste RED por API ausente.
- [ ] Implementar armazenamento compartilhado, recuperação após lock e antes debackup/carregar, interceptação stdio e fronteira callFn. Falha interrompe emulação sem publicar dados parciais.
- [ ] Executar python -m unittest discover -s tests -p test_safe_save.py -v, testesruntime e suíte completa. Esperado0falhas; documentar qualquer skip.
- [ ] Commit com evidências no ledger.

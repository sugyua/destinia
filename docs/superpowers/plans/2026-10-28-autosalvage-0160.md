# Auto-Salvage 0.16 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an explicit, filtered batch dismantle flow that preserves protected and equipped items and uses the original ARM game menu for every dismantle.

**Architecture:** A pure policy selects eligible inventory records from the active filter. The host builds a preview, revalidates each record and fingerprint immediately before calling the original menu flow, and reports completion/errors in the existing inventory overlay. The native protection hook is extended to cover the dismantle confirmation state.

**Tech Stack:** C++17, SDL host overlay, Unicorn ARM integration, existing inventory sidecar and tests.

**Spec:** 0.16 scope delegated in the user conversation; thermal guard only counts CPU and primary GPU temperature, with a stop threshold of 68 C.
